# Evidencias

Se organizó esta carpeta como ubicación de los soportes de la actividad de arquitectura y DevSecOps.

Los resultados de los análisis automatizados se consultan en la pestaña **Actions** del repositorio, donde se encuentran los pasos y registros de ejecución de los workflows de Flake8, Bandit, pip-audit y generación de diagramas.

Las capturas y los registros se incorporan cuando se obtienen de una ejecución real. No se registraron resultados simulados ni se marcaron análisis como aprobados sin verificar su ejecución.
